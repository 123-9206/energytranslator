# 公开展示版本修改说明

整理日期：2026-10-17（澳大利亚悉尼时间）。
来源：用户提供的 2026-09-28 源码交接包，共 348 个文件。
本说明记录公开准备工作，不代表全部业务功能已验证或可直接投入生产。

## 公开范围

保留 `backend/`、`admin/`、`miniprogram/` 三个主要应用及原有业务代码。
删除原始交接说明、凭据文件、内部开发/部署手册、历史审计报告、专利交底和软著材料。
原商业网站、获客表单、二维码与旧版后台 HTML 未放入此版本。

这些材料的移除是从公开包中排除，不构成对原始材料权属或有效性的判断。
本次没有使用原生产服务器，也没有尝试登录原账号。

## 配置与行为修改

| 部分 | 修改 |
| --- | --- |
| JWT | 移除原固定值，通过 `JWT_SECRET` 注入；未设置时不能正常启动 |
| 私有配置 | 新增空值 `.env.example` 与本地随机生成脚本；生成的 `.env` 被 Git 忽略 |
| 管理员 | 新增显式密码引导创建；已有账号不重置、不提升权限，日志不输出密码 |
| 演示账号 | 删除固定口令与启动时强制重置行为；新建时生成随机口令 |
| 演示数据 | 默认不初始化；显式开启后生成合成示例，移除示例联系人电话及原地址 |
| 演示登录 | 默认关闭；`prod` profile 下拒绝免密演示登录 |
| 设备网络 | 协议采集及设备控制默认关闭，演示设备使用文档示例网段 |
| 管理后台 | 默认代理改为本机后端；不再自动请求原线上服务 |
| 小程序 | AppID 改为访客占位，清空云环境和订阅模板 ID，上传脚本使用个人环境配置 |
| 部署 | 重写为本地 Docker Compose，端口仅绑定回环地址，修正后端构建目录 |
| Maven | 补上原 Modbus4J 依赖所需的 JitPack 仓库；保留原依赖版本 |
| 项目说明 | 新增英文 README、中文上手和上传说明、忽略规则及源码扫描工作流 |

默认关闭外部功能会改变原先的演示行为；这是本地展示配置的一部分。
需要硬件、外部模型或微信服务时，使用你自己的环境与账号单独配置。
本次没有把该系统改造成 MCP Server，也没有创建 GitHub 仓库或替你公开发布。
